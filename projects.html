Alibaba Cloud Intelligence Group

Campus platform and retrieval evaluation

Problem

Campus services needed dependable transaction handling, while the retrieval system needed evidence that its search quality held up beyond a few examples.

What I built

I implemented backend workflows and created a repeatable retrieval benchmark with 778 source entries and 6,562 evaluation queries.

Result

The BGE pipeline reached 76.40% Top-1 and 91.34% Top-3 accuracy, supported by 371 automated tests and a 999-item post-regression check.

  • Python
  • FastAPI
  • PostgreSQL
  • RAG
  • Evaluation

FessorAI

AI textbook authoring workflow

Problem

Long-form educational content requires research, structure, drafting, and review, but generic chat interfaces hide those stages inside one conversation.

What I built

I designed a six-stage workflow and a 28-tool assistant that makes each authoring step visible, editable, and easier to review.

Result

The product turns an open-ended generation task into a structured process where authors can inspect intermediate work rather than accept a black-box output.

  • TypeScript
  • React
  • Agent workflows
  • Product design

FocusTrail

Local-first adaptive task coach

Problem

Task plans become obsolete as soon as priorities change, and sending every personal detail to a remote model creates unnecessary privacy risk.

What I built

I modeled work as a task graph, added adaptive replanning, and designed privacy-aware routing that keeps sensitive requests local when possible.

Result

The prototype treats planning as a changing system rather than a static checklist, while making the privacy decision part of the architecture.

  • Python
  • Task DAGs
  • Local AI
  • Privacy routing
